Руководство: Как создать плагин для Powramp и подключить Genius API

1. Архитектура плагина для Powramp

Powramp поддерживает расширения или может управляться через локальный сервер / плагины. Чтобы внедрить поиск текстов:

  • Плагин перехватывает метаданные текущего трека (название, артист).
  • Делает запрос к бэкенду или напрямую в Genius API.
  • Парсит HTML-страницу трека Genius или использует неофициальные обертки API для получения текста.

2. Получение данных с Genius API

Для работы с Genius нужно зарегистрироваться на Genius API Developers и получить токен доступа (Client Access Token).

// Пример запроса к Genius API поиска песни
async function searchGenius(artist, track) {
    const token = 'ВАШ_GENIUS_ACCESS_TOKEN';
    const query = encodeURIComponent(`${artist} ${track}`);
    const res = await fetch(`https://api.genius.com/search?q=${query}`, {
        headers: { 'Authorization': `Bearer ${token}` }
    });
    const data = await res.json();
    return data.response.hits[0]?.result?.path; // Путь к странице текста
}

3. Реализация Караоке (Синхронизация по времени)

Для караоке-подсветки используется LRC-формат (время в миллисекундах или секундах). Плагин сопоставляет текущую позицию аудиоплеера Powramp с таймкодами строк текста и добавляет класс активной строке.
